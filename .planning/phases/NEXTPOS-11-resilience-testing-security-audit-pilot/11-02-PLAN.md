# Phase 11 Plan 2: 1,000,000-Row Heavy Load Performance & Memory Profiling

**Plan ID:** `11-02`  
**Phase:** `NEXTPOS-11-resilience-testing-security-audit-pilot`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement heavy scale benchmark in `crates/pos-core/tests/scale_benchmark_tests.rs`:
   - Generate synthetic dataset: 50,000 products, 200,000 sales invoices, and 1,000,000 stock ledger entries.
   - Profile memory footprint: pure Rust `pos-core` memory resident set size (RSS) stays under 150MB.
   - Benchmark latency targets under full load:
     - Barcode point lookup: target < 25ms.
     - Cart item addition: target < 15ms.
     - Checkout transaction commit (write invoice + deduct stock + update ledger): target < 80ms.
     - End-of-day Z-Report calculation: target < 200ms.
2. Assert zero table scans using `EXPLAIN QUERY PLAN` verification.
