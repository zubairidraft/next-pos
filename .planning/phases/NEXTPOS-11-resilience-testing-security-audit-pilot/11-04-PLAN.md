# Phase 11 Plan 4: Bilingual Cashier Guide & Automated Diagnostic Health Checker

**Plan ID:** `11-04`  
**Phase:** `NEXTPOS-11-resilience-testing-security-audit-pilot`  
**Target:** `apps/desktop`  

## Objectives
1. Implement Automated Health Diagnostic Tool in `apps/desktop`:
   - `SystemDiagnosticsModal.tsx`: Runs automated checks on launch or via Help menu:
     - SQLite database health (`PRAGMA quick_check`).
     - Available disk space (warns if < 2 GB).
     - Thermal printer connectivity (ESC/POS probe test print).
     - USB barcode scanner input test field.
     - System clock skew check.
2. Produce Bilingual Cashier Training Documentation:
   - Cashier Quick Reference Card (`docs/cashier-cheat-sheet.pdf` / markdown) in English and Urdu Nastaliq covering:
     - Keyboard shortcuts (F1 search, F2 hold, F12 pay, F8 discount, etc.).
     - Cash session open / close procedures.
     - Handling barcode misreads or weight scale items.
     - Emergency offline procedures during extended power outages.
