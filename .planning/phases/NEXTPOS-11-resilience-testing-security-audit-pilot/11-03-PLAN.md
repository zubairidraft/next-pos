# Phase 11 Plan 3: ASVS Level 1 Local Security Audit & Key Isolation Hardening

**Plan ID:** `11-03`  
**Phase:** `NEXTPOS-11-resilience-testing-security-audit-pilot`  
**Target:** `crates/pos-core` & `apps/desktop`  

## Objectives
1. Security verification and hardening:
   - Audit SQLCipher encryption key handling: key zeroized in memory immediately after connection initialization.
   - Audit Tauri IPC command boundary: every sensitive command (void transaction, price override, cash drawer manual open, settings edit) verifies user role and session token.
   - Log sanitization: review all `tracing` / `log` output to ensure PINs, passwords, and customer telephone numbers are never logged in plaintext.
   - Review file permissions of SQLite database file, WAL files, and backup archives on Windows (`icacls` restricted to current user).
2. Tests in `crates/pos-core/tests/security_audit_tests.rs`.
