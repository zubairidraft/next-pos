# Phase 11 Plan 1: Power-Cut Simulation & Crash-Resilience Stress Harness

**Plan ID:** `11-01`  
**Phase:** `NEXTPOS-11-resilience-testing-security-audit-pilot`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement crash simulation harness in `crates/pos-core/tests/resilience_tests.rs`:
   - Rapid concurrent transactional writes (sales checkouts, stock movements, khata ledger entries).
   - Simulate abrupt process kills (`std::process::exit` or abort) during active multi-statement write transactions.
   - Verify upon restart:
     - SQLite `PRAGMA integrity_check` returns `ok`.
     - No half-written or orphaned invoices exist (either fully committed or clean rollback).
     - Inventory stock ledger balances match physical line sums.
2. Verify startup recovery time under cold boot is under 1.5 seconds.
