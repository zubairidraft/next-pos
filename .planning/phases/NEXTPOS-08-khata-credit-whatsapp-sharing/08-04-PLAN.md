# Phase 8 Plan 4: Khata Desktop UI & WhatsApp Sharing Interface

**Plan ID:** `08-04`  
**Phase:** `NEXTPOS-08-khata-credit-whatsapp-sharing`  
**Target:** `apps/desktop`  

## Objectives
1. Implement Khata UI in `apps/desktop`:
   - `KhataView.tsx`: Tabbed view for Customer Khata and Vendor Khata.
   - Balance cards: Total Receivables (واجب الوصول), Total Payables (واجب الادا), Overdue accounts.
   - Customer detail modal showing ledger entries, invoice drill-down, and date filter.
   - "Receive Payment" dialog with automatic FIFO invoice preview or manual allocation.
2. WhatsApp share trigger:
   - "Send WhatsApp Reminder" action button opening formatted WhatsApp Web / WhatsApp Desktop URL.
   - Quick copy button for statement summary.
3. Thermal statement printing shortcut:
   - Prints account ledger directly via Phase 7 ESC/POS thermal engine.
