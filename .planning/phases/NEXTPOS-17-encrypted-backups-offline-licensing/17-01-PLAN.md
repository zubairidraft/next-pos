# Phase 17 Plan 1: Encrypted Backups & Offline Licensing

**Plan ID:** `17-01`  
**Phase:** `NEXTPOS-17-encrypted-backups-offline-licensing`  
**Wave:** 1  
**Target:** `apps/desktop/src-tauri`, `BackupView.tsx`, `LicenseView.tsx`, `api.ts`  

## Objectives
1. Connect `CryptoBackupService` & `SnapshotManager` in `pos-core`:
   - `create_live_snapshot()`: Non-blocking zero-latency snapshot using SQLite `VACUUM INTO`.
   - `list_database_snapshots()`: Scans snapshot directory with file size and timestamp metadata.
   - `export_backup(password, destination_file)`: Encrypted single-file `.kpos` package with Argon2id key derivation and SHA-256 tamper verification.
   - `restore_backup(password, backup_file)`: Safe restoration with automatic `.pre_restore_safety` snapshot.
2. Connect `HardwareFingerprint` & `LicenseStore`:
   - `get_machine_identifier()`: Dual-hash hardware fingerprint (OS Installation GUID + System Disk Serial).
   - `get_license_info()`: Evaluates 14-day offline trial, grace period, and active cryptographic tier.
   - `activate_license_token(token)`: Verifies and installs Ed25519-signed commercial offline license token.
