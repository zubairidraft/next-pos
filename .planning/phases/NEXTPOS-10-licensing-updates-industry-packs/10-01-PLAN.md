# Phase 10 Plan 1: Offline Ed25519 License Verification & Machine Fingerprint

**Plan ID:** `10-01`  
**Phase:** `NEXTPOS-10-licensing-updates-industry-packs`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement offline license engine in `crates/pos-core/src/licensing/license.rs`:
   - Ed25519 public key signature verification without network roundtrip.
   - License payload schema: `store_name`, `machine_id`, `tier`, `expires_at`, `features`.
   - 14-day offline trial mode with monotonic clock check.
2. Implement hardware fingerprint generator in `crates/pos-core/src/licensing/fingerprint.rs`:
   - Query stable hardware identifiers on Windows (BIOS UUID, Motherboard Serial).
   - SHA-256 hash formatted as clean customer-facing registration code (e.g. `KPOS-XXXX-XXXX-XXXX`).
3. Tests in `crates/pos-core/tests/licensing_tests.rs`.
