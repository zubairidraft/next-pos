# Phase 10 Plan 4: License Activation UI & Industry Pack Desktop Switcher

**Plan ID:** `10-04`  
**Phase:** `NEXTPOS-10-licensing-updates-industry-packs`  
**Target:** `apps/desktop`  

## Objectives
1. Implement License Management UI in `apps/desktop`:
   - `LicenseView.tsx`: Displays Machine ID / Fingerprint with one-click copy button.
   - Status card: Licensed / Trial Active (days remaining) / Expired banner.
   - License key input / drag-and-drop license file loader (`.lic`).
   - Feature flags display: Grocery Pack, Electronics Pack, Multi-Till.
2. Industry Pack UI toggles:
   - Grocery mode: Scale barcode test tool and price/weight parser configurator.
   - Electronics mode: IMEI serial prompt popup during POS scan.
   - Apparel mode: Matrix grid variant selector during product creation.
