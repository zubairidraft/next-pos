# Phase 5 Plan 3: Thermal Barcode Label Generation Engine

**Plan ID:** `05-03`  
**Phase:** `NEXTPOS-05-stock-audits-discrepancies-label-designer`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement `crates/pos-core/src/hardware/label.rs`:
   - Label specifications for standard retail sticker sizes: 38x25mm and 50x30mm.
   - Command generators for TSPL (Taiwan Semiconductor / Xprinter / Rongta barcode printers).
   - Code128 barcode generation and human-readable SKU/barcode text.
   - 1-bit monochrome raster image rendering for Urdu Nastaliq store and item names.
2. Output formats: Raw byte command sequence ready for direct USB/serial printer transmission.
3. Tests in `crates/pos-core/tests/label_generator_tests.rs`.
