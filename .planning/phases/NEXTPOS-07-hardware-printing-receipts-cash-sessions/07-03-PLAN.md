**Plan ID:** `07-03`  
**Phase:** `NEXTPOS-07-hardware-printing-receipts-cash-sessions`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement `crates/pos-core/src/domain/refund.rs`:
   - `post_return(conn: &mut Connection, return_req: ReturnRequest) -> Result<CompletedReturn>`
   - Validates return against original sale invoice lines (cannot return more items than originally purchased).
   - Records positive inbound `stock_movements` (restoring inventory).
   - Generates credit note / refund record with sequence `RET-`.
   - Adjusts cashier shift cash balance or customer credit ledger.
2. Return receipt ESC/POS printer formatting.
3. Tests in `crates/pos-core/tests/return_posting_tests.rs`.
