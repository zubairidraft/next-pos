**Wave:** 2  
**Target:** `apps/desktop/src/components/MasterDataView.tsx`  

## Objectives
1. Replace initial mock state in `MasterDataView.tsx` with live database calls:
   - Load categories via `api.listCategories()`
   - Load brands via `api.listBrands()`
   - Load units via `api.listUnits()`
2. Wire the creation forms:
   - Add Category $\rightarrow$ `api.createCategory(name, name_ur)`
   - Add Brand $\rightarrow$ `api.createBrand(name, name_ur)`
   - Add Unit $\rightarrow$ `api.createUnit(code, name, decimals)`
3. Ensure optimistic update and instant table reload upon saving.
