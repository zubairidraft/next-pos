# Phase 4 Plan 1: Immutable Stock Movement Ledger & Balance Cache

**Plan ID:** `04-01`  
**Phase:** `NEXTPOS-04-purchasing-costing-stock-ledger`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement `crates/pos-core/src/domain/inventory.rs`:
   - `StockMovement` domain entity and append-only repository.
   - `inventory_balances` materialized cache updater.
   - Atomic transaction guarantees: appending a movement always updates cached balance simultaneously.
2. Query helpers:
   - `get_on_hand_qty(variant_id: &str) -> Qty`
   - `get_stock_history(variant_id: &str, limit: usize) -> Vec<StockMovement>`
3. Unit tests in `crates/pos-core/tests/inventory_ledger_tests.rs`.
