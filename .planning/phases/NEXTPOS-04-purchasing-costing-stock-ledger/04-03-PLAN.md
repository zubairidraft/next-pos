# Phase 4 Plan 3: Negative Stock Policy Enforcement & Vendor Directory

**Plan ID:** `04-03`  
**Phase:** `NEXTPOS-04-purchasing-costing-stock-ledger`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement Negative Stock Guard in `crates/pos-core/src/domain/inventory.rs`:
   - Checks business setting `stock_policy`.
   - If policy == `Block`, prevents recording any outbound movement that exceeds current on-hand balance.
   - Returns explicit error with SKU, requested qty, and available qty.
2. Implement Vendor Directory in `crates/pos-core/src/domain/party.rs`:
   - CRUD for vendor parties (`name`, `name_ur`, `phone`, `ntn`, `opening_balance_paisa`).
3. Automated tests in `crates/pos-core/tests/negative_stock_tests.rs`.
