# Phase 14 Plan 1: Native Raw ESC/POS Windows Spooler & Network Printer Service

**Plan ID:** `14-01`  
**Phase:** `NEXTPOS-14-hardware-peripherals-escpos-printing`  
**Wave:** 1  
**Target:** `apps/desktop/src-tauri`  

## Objectives
1. Implement a Windows raw printer spooler module (`winspool.drv` FFI) in `src-tauri` that can send raw ESC/POS byte streams directly to any installed Windows printer driver without opening print dialogs.
2. Implement a TCP socket sender for raw network thermal printers (e.g. `192.168.1.200:9100`).
3. Implement printer discovery: query installed Windows printers using PowerShell WMI / Windows API so the user can pick from an actual list of devices.
4. Support drawer kick pulse generation (`ESC p 0 25 250`) and full paper cut (`GS V 66 0`).
