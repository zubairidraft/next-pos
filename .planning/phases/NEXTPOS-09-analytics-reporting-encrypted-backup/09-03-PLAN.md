# Phase 9 Plan 3: AES-256-GCM Encrypted USB Backup & Verified Restore

**Plan ID:** `09-03`  
**Phase:** `NEXTPOS-09-analytics-reporting-encrypted-backup`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement encrypted backup service in `crates/pos-core/src/backup/crypto_backup.rs`:
   - Package database snapshot with metadata manifest (schema version, timestamp, SHA-256 hash).
   - AES-256-GCM encryption with Argon2id password-derived key or Windows DPAPI machine key.
   - Archive compression (`.kpos` bundle).
2. Verified restore engine:
   - Verify archive signature and decrypt payload in isolated memory/scratch space.
   - Verify SQLite schema compatibility and PRAGMA integrity check before swap.
   - Atomic replacement of active database with pre-restore safety copy.
3. Tests in `crates/pos-core/tests/encrypted_backup_tests.rs`.
