# Phase 3 Plan 2: High-Speed Excel & CSV Catalog Importer (50,000+ Items)

**Plan ID:** `03-02`  
**Phase:** `NEXTPOS-03-catalog-high-volume-data-import`  
**Wave:** 1  
**Target:** `crates/pos-core`  

## Objectives
1. Add `csv = "1.3"` and `calamine = "0.26"` dependencies to `crates/pos-core/Cargo.toml`.
2. Implement high-speed catalog importer in `crates/pos-core/src/domain/importer.rs`:
   - Streaming reader for CSV and native Excel (`.xlsx`, `.xls`).
   - In-memory ID caches for `categories`, `brands`, and `units` to prevent database roundtrips.
   - Chunked batch transactions (2,500 - 5,000 rows per transaction) using cached prepared statements.
   - Validation engine:
     - Missing required fields (SKU, Name, Unit, Price).
     - Duplicate SKU detection within the import batch and against the existing database.
     - Duplicate barcode detection.
     - Flexible column header parsing (case-insensitive & alias-friendly).
   - `ImportSummary` reporting:
     - `total_rows: usize`
     - `imported: usize`
     - `skipped: usize`
     - `errors: Vec<ImportRowError>` (row index, SKU, error message).
     - `duration_ms: u128`
3. Write high-volume benchmark test in `crates/pos-core/tests/importer_benchmark_tests.rs`:
   - Generate a synthetic 50,000-row catalog dataset in memory.
   - Import the 50,000 items into SQLite.
   - Assert `imported == 50,000` and `duration < 30.0` seconds on Windows.
