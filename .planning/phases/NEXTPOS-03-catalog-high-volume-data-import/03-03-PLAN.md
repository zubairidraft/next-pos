# Phase 3 Plan 3: Desktop Catalog Management & Sub-100ms Search UI

**Plan ID:** `03-03`  
**Phase:** `NEXTPOS-03-catalog-high-volume-data-import`  
**Wave:** 2  
**Target:** `apps/desktop`  

## Objectives
1. Build `apps/desktop/src/components/CatalogView.tsx`:
   - Interactive high-speed product catalog table.
   - Search-as-you-type input with immediate scanner focus.
   - Filters by Category and Brand.
   - Detailed product view showing:
     - SKU, English & Urdu Name, Category, Brand, Base Unit.
     - Barcode tags.
     - Multi-tier pricing (Retail, Wholesale).
     - Packaging units (e.g. Carton = 24 Pcs).
2. Build bilingual "Add / Edit Product" Drawer / Modal:
   - Barcode generator / scanner input with duplicate warning.
   - English & Urdu Nastaliq product name inputs.
   - Category & Brand dropdown selectors.
   - Base Unit selection with decimal precision indicator.
   - Packaging unit conversion factor inputs (milli-units calculation).
   - Retail & Wholesale pricing inputs in PKR (`Paisa` integer contract).
3. Update `en.json` and `ur.json` translation files with full catalog terminology.
