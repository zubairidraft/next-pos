# Phase 3 Plan 1: Core Catalog Domain Models, Repositories & Fast Search

**Plan ID:** `03-01`  
**Phase:** `NEXTPOS-03-catalog-high-volume-data-import`  
**Wave:** 1  
**Target:** `crates/pos-core`  

## Objectives
1. Add `V2__catalog_indexes.sql` migration to index `barcodes(value)`, `products(sku)`, `products(name)`, `products(name_ur)` for instant scanner lookups.
2. Implement catalog domain models and repository in `crates/pos-core/src/domain/catalog.rs`:
   - `Product`, `ProductVariant`, `VariantUnit` (packaging conversions), `Barcode`, `Price`, and `PriceList`.
   - Full CRUD support with atomic transactions.
   - Packaging unit conversion logic with integer milli-units `Qty` (e.g. carton of 24 = `24,000` milli-units).
   - Multi-tier price mapping (`Paisa(i64)` per price list).
3. Implement high-speed indexed search:
   - Query by exact Barcode, exact SKU, or bilingual name prefix/substring.
   - Target query latency: < 10ms for exact barcode scan, < 50ms for dual-script text search.
4. Comprehensive test suite in `crates/pos-core/tests/catalog_tests.rs`.

## Tasks
