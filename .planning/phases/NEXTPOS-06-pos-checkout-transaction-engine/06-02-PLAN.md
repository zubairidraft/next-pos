**Plan ID:** `06-02`  
**Phase:** `NEXTPOS-06-pos-checkout-transaction-engine`  
**Target:** `crates/pos-core`  

## Objectives
1. Implement `crates/pos-core/src/domain/sale.rs`:
   - `post_sale(conn: &mut Connection, sale_request: PostSaleRequest) -> Result<CompletedSale>`
   - Wrapped in atomic SQLite `BEGIN IMMEDIATE` transaction:
     - Enforces negative stock guard for each line item.
     - Appends negative `stock_movements`.
     - Inserts into `sales` and `sale_lines`.
     - Allocates tenders (`cash`, `card`, `jazzcash`, `easypaisa`, `raast`, `credit`).
     - Updates customer Khata balance if credit is tendered.
     - Increments invoice sequence `INV-`.
2. Tests in `crates/pos-core/tests/sale_posting_tests.rs`.
