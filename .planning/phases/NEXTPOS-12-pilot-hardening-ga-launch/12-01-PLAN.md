# Phase 12 Plan 1: Pilot Feedback Refinements & High-Contrast Touch Ergonomics

**Plan ID:** `12-01`  
**Phase:** `NEXTPOS-12-pilot-hardening-ga-launch`  
**Target:** `apps/desktop`  

## Objectives
1. Implement cashier ergonomics & feedback refinements in `apps/desktop`:
   - High-contrast sunlight-readable theme toggle for glare-prone shop counters.
   - Touchscreen-optimized numpad mode (minimum 48x48px button targets) for all-in-one touch screens.
   - Scanner rapid-fire input queue buffer: debounces hardware scanner input to prevent missed keystrokes during rapid barcoding.
   - Customizable receipt density slider (1-5) and feed cut margin in hardware settings.
2. Build verification: Ensure clean TypeScript check and fast frontend load (< 400ms).
