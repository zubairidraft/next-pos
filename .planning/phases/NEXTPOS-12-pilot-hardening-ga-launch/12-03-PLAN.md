# Phase 12 Plan 3: Offline Dealer License Provisioning CLI Tool

**Plan ID:** `12-03`  
**Phase:** `NEXTPOS-12-pilot-hardening-ga-launch`  
**Target:** `crates/pos-license-cli`  

## Objectives
1. Implement standalone offline dealer CLI tool in `crates/pos-license-cli`:
   - Cryptographic signing tool using Ed25519 dealer master private key.
   - Command-line arguments: `--hardware-id <id>`, `--store-name <name>`, `--tier <standard|pro|enterprise>`, `--expiry <date|perpetual>`, `--features <comma-separated>`.
   - Generates signed `.lic` file or Base64 license token for distribution to local merchants without internet connection.
2. Verification command `--verify <license-file>` to inspect and test license validity.
3. Tests in `crates/pos-license-cli/tests/cli_tests.rs`.
